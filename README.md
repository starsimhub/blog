# Starsim blog

This repo contains the content for Starsim's blog: news, tutorials, and summaries of research built with [Starsim](https://starsim.org) and its disease-model ecosystem (Covasim, FPsim, HPVsim, HIVsim, STIsim).

https://starsim.org/blog

The site is built with [Quarto](https://quarto.org). Each post is a folder under `posts/`. To add one, see [`CONTRIBUTING.md`](CONTRIBUTING.md), or [reach out](mailto:info@starsim.org).
